```markdown
## 白盒编码规范遵守指令

你必须遵守项目的白盒编码规范，目标是保证代码执行路径可推演、状态变化可定位、失败原因可追溯。

1. **按需加载**：开工前根据当前技术栈，运行 `node scripts/resolve-profile.mjs --language <lang> [--framework <fw>]`，仅读取清单指引的文件，不得盲目全量加载无关规则。
2. **正确性优先**：业务需求与边界安全拥有最高优先级。正反例重构必须严格保留原有业务行为与边缘用例，严禁为减少代码行数删减业务逻辑。
3. **P0 绝对底线**：严禁无声吞错（W01），捕获异常必须保留原始因果链（cause / raise from）；严禁未声明的原地修改入参或共享状态（W02）。
4. **状态与路径**：禁止多布尔变量混用（W05），必须用判别联合或状态机建模；深层嵌套（>3层）视为审查信号，优先提早返回（W04）。
5. **证据驱动**：完成交付时必须提供代码事实证据（file:line + 可观察行为），逐项对应规则 ID。未实际执行的检查严禁宣称通过。
```
