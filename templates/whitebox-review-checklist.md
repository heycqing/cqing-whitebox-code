# 白盒代码审查清单 (Whitebox Review Checklist)

> 用途：供人工审阅者（Reviewer）或 AI 审阅 Agent 对 Pull Request 进行结构化白盒审查。  
> 评判原则：**事实驱动**。必须给出具体的代码文件与行号证据。判定标准为“是否达成可观察质量目标”，**不得仅因实现风格与文档示例不同而判错**。

## 审阅结论与处置

- [ ] **全量通过 (Approved)**：所有 P0/P1/P2 项目均满足契约或合规例外，具备完整证据。
- [ ] **需修改后重新审查 (Changes Requested)**：存在 P0/P1 未满足项，请根据上述修复建议整改后重测。
- [ ] **附条件放行 (Conditionally Approved)**：存在非核心 P1/P2 偏差，已登记在任务追踪列表，承诺于下一迭代重构。
